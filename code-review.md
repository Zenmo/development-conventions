Code review
===

## Four eyes principle

Code must be reviewed and approved by one other person. No code goes to the main branch without a second approval.

This can be achieved through different means:

- Pull Requests 
- The "group merge" on wednesday
- Pair programming

## Exemptions

The following cases are exemptions where a review might not be necessary:

- Code in repositories for a specific project or a single client
  - Each project has their own guidelines for code review
- Changes which are mostly content and use existing code patterns 
  - For example website edits for zenmo.com, holons.energy, isie.energy, lux.energy
